jikz — live demos

Every preview below is rendered by the code shown in its Code tab — not by a hidden harness. Paste the code into your app (with npm install jikz) and it works verbatim. Serving this page: it needs an HTTP server (ES modules can't load from file://). Run npm run dev and open the Vite URL — demos then use the live source. Or run npm run build and serve this folder with any static server — demos then use the built dist/jikz.js, the exact artifact npm users get.

To reuse any example:
  1. npm install jikz
  2. Copy the code from a Code tab into a file (e.g. diagram.js).
  3. Call the exported render(container) with any DOM element: import render from './diagram.js'; render(document.getElementById('out')).
