jikz — live demos

Every preview below is rendered by the code shown in its Code tab — not by a hidden harness. Each card is a real module in examples/: type-checked by tsc and snapshot-tested by vitest, so the examples can never drift from the library. Paste the code into your app (with npm install @ozan.e/jikz) and it works verbatim.
Serving this page: run npm run dev and open the Vite URL — the examples import the live library source (src/) via the jikz alias.

To reuse any example:
  1. npm install @ozan.e/jikz
  2. Copy the code from a Code tab into a file (e.g. diagram.ts).
  3. Call the exported render(container) with any DOM element: import render from './diagram'; render(document.getElementById('out')).
