# jikz — generated API reference

Every exported symbol, generated from the source by TypeDoc
(`npm run docs:api`). Use the sidebar or the search box to find a
class, function or type; the prose that explains *when* to reach for
each one lives in the hand-written guide — the **Documentation** link
in the header above.

This page is written by hand at `docs/api-readme.md`, and is the only
part of the API site that is: everything else comes from the doc
comments in `src/`. It deliberately does NOT reuse the guide's
`docs/README.md` — that file's links are repo-relative, and TypeDoc
rewrites such targets into `api/media/*.md`, which browsers show as
plain text rather than pages.
